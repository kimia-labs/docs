Kimia is in private beta. The app asks for an invite code the first time you connect
a wallet, before you can do anything else.

## Entering your code

<Steps>
  <Step title="Connect your wallet">
    Open [beta.kimia.live](https://beta.kimia.live) and press **Connect Wallet**.
    Choose Phantom, MetaMask or Solflare. Use the wallet you want to trade with.
  </Step>
  <Step title="Enter your invite code">
    Codes read `KIM` followed by eight letters or digits, for example `KIMA1B2C3D4`.
    Paste it and press **Continue**. If you arrived through someone's invite link,
    the code is already filled in.
  </Step>
  <Step title="Read and accept the risk notice">
    A **Before you trade** screen asks you to confirm three things: that Kimia is
    unaudited beta software, that you can lose some or all of what you commit, and
    that your decisions are your own. Tick each and press **I understand**. This also
    records your agreement to the [Terms of Use](/legal/terms-of-use) and
    [Privacy Policy](/legal/privacy-policy).
  </Step>
</Steps>

## Rules worth knowing

**The code is permanent.** Whoever invited you becomes your referrer, and that cannot
be changed later. See [Referrals](/using-kimia/referrals).

**There is a seven day window.** A code can only be entered within 7 days of Kimia
first setting up your trading wallet, which usually happens when you sign up.

**One code per account.** The code is claimed by your Kimia account, shown under the
field as "Claiming as" and an address. If you connected the wrong wallet, use the
**Use a different wallet** link before entering a code.

**Once is enough.** After your account is admitted, you are not asked for a code again,
on this device or any other. The risk notice is remembered per browser, so it appears
again on a new device.

## If your code is refused

| Message | What it means |
|---|---|
| That is not the shape of a Kimia code | Check for a typo. It must be `KIM` plus eight letters or digits |
| No such code | The code does not exist. Check it with whoever sent it |
| That is your own code | You cannot invite yourself |
| That code belongs to someone you referred | Referrals cannot loop back |
| This one has closed | Your 7 day window has passed |

## Getting a code

Ask someone already using Kimia for their invite link. The public waitlist at
[waitlist.kimia.live](https://waitlist.kimia.live) is the other route in.
